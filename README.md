# Teacher's Day 2026 — A Teacher's Impact

A mobile-first React/Vite interactive Teacher's Day experience by Ahmed.

## Features

- Personalized teacher name
- Cinematic envelope opening
- Handwritten-style type-on letter animation
- English + Urdu message
- Teacher's Wall
- Hidden surprise
- Generated ambient music using Web Audio
- No music API/key required
- Replay
- PNG export
- A4 PDF export
- Native share + clipboard fallback
- Responsive mobile/tablet/desktop layout
- Reduced-motion support

## Run locally

```bash
npm install
npm run dev
